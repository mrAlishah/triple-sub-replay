Each release contains the APK asset **`TripleSub-Replay.apk`** and its **`.sha256`** checksum file. To update in place, your installed build must share the APK's package identity and signing certificate. Back up Practice data before uninstalling.

**Unreleased work is not included in this table.** Development features on `mydevelop` can be ahead of the latest published APK. See [Unreleased changes](../../myCHANGELOG.md).

## Original project

TripleSub Replay is a customized fork of [DualSub Replay](https://github.com/hoangkien1703/dual-sub-replay) by Hoang Trung Kien. The original project's [releases](https://github.com/hoangkien1703/dual-sub-replay/releases) and [website](https://hoangkien1703.github.io/dual-sub-replay/) are maintained separately.
