## Highlights

- **Triple subtitles:** three independently selectable language lines—for example, German, English and Persian.
- **Word learning:** select words in subtitle text and view meanings in supported languages.
- **Practice:** saved vocabulary, examples and spaced-repetition review.
- **AnkiDroid:** extended multilingual vocabulary sending.
- **Persian and RTL:** improvements to rendering and word selection.
- **Import/export:** preserve study data and multilingual translations.

## Install

Open the [v2.7.14 release](https://github.com/mrAlishah/triple-sub-replay/releases/tag/v2.7.14), expand **Assets**, and download **`TripleSub-Replay.apk`**. Android 8.0 or later is required.

**Release-history note:** this first APK was produced with release-specific build adjustments outside the tagged source tree; see the original release description for provenance. Do not assume its package/signing identity matches another build.
