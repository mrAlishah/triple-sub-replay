# TripleSub Replay v2.8.2 — Translation actions and settings

[← TripleSub Replay README](../../README.md) · [All releases](README.md) · [Fork changelog](../../myCHANGELOG.md)

**Published:** October 28, 2026 (UTC) · **[Release and APK](https://github.com/mrAlishah/triple-sub-replay/releases/tag/v2.8.2)**

## What's new

### Open selected text in Google Translate

A new **Open in Google Translate** action in the **word-selection popup** sends selected subtitle text to the installed Google Translate app. The same text-selection capability is available for supported words and examples in Vocabulary and Practice.

This word-selection menu is different from the separate per-card **Re-translate with AI** popup added to newer development code; the latter is not confirmed as a v2.8.2 APK feature.

### Easier subtitle settings

- Collapsible sections for Original Subtitle, Subtitle 1 and Subtitle 2.
- Settings panels initially collapsed for a cleaner view.
- **Whole sentence** is the default caption format for fresh settings.
- Existing language and layout choices remain available.

### Reliability

Word-selection interactions and subtitle translation actions were improved, with upstream playback and fullscreen changes included.
