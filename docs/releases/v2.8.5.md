## What's new

### Choose how captions are translated

The release documents four modes:

| Mode | Purpose |
| --- | --- |
| Google Translate | Fast online translation (default) |
| AI translation (best quality) | Show Google text while waiting for improved AI |
| AI only | Wait for AI, with Google fallback if AI fails |
| On this device only | Local translation without sending subtitle text online |

AI translation in the release uses a configured AI provider and is designed to deliver results progressively. Model selection, caching, batching and rate-limit handling were improved. The original release notes describe API-key configuration; newer account-based ChatGPT Subscription flows belong to later source changes unless confirmed in a tagged APK.

### German grammar highlighting

Original German subtitles can receive offline part-of-speech classification and grammatical colors. The release notes identify nouns, verbs, adjectives, adverbs, pronouns, prepositions, conjunctions and determiners; variants such as `de-DE` are supported.

### Clearer and more accurate subtitles

The release documents improvements to sentence endings, punctuation, line alignment, automatically generated caption handling, HTML-text artifacts, cache reuse and fallback when AI is unavailable.

## How to try it

1. Install [v2.8.5](https://github.com/mrAlishah/triple-sub-replay/releases/tag/v2.8.5) from the fork's Assets.
2. Choose a captioned YouTube video.
3. Open the relevant **Translation** settings.
4. Pick a mode and configure an AI provider if needed.
5. Watch the initial subtitles and subsequent AI improvements when available.

See the [Translation and AI guide](../user-guide/ai-translation.md). The screenshots shared from current development builds may depict controls added after this version and are **not** presented as v2.8.5 screenshots.
