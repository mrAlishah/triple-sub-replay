## Your first learning session

1. **Watch:** open a YouTube video with available captions.
2. **Read:** select the Original Subtitle and up to two translated subtitle slots.
3. **Replay:** tap the **Play** icon for the sentence you want to hear again.
4. **Understand:** use word selection or your chosen translation mode.
5. **Save:** add useful words and phrases to Practice.
6. **Review:** use **Practice due words** and optionally export or send to Anki.
