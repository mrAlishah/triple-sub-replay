# Practice and vocabulary

[← User guide](README.md) · [Anki and backups](anki-backup.md)

Use **Practice** to save language-learning material and review it later.

## Save a word or phrase

1. While reading subtitles, select a word or phrase.
2. Look up its meaning using the available word-learning action.
3. Save it with its example sentence and source information.
4. Open **Practice** to see the saved item.

Additional translations, meanings and personal notes may be available in newer customized builds. Saved-word storage is designed to retain review history when compatible existing records are saved again.

## Find words from one video

1. Open **Practice**.
2. Tap **Source / Video**.
3. Choose **All Sources** or a source-video entry.
4. Use the search field to find a word or meaning.

The **Source Title** can identify the originating video. A missing title may be shown as an unknown source rather than discarded.

## Review due words

1. Tap **Practice due words** when available.
2. Read the prompt and try to recall the meaning.
3. Reveal the answer.
4. Choose the review rating offered by the app.

The review schedule is preserved in the saved study data. Do not delete the app to resolve an update error before making a backup.

## Export and import

Use the Practice **Export** and **Import** controls. The existing detailed specification is available in [Practice import and export](../practice-transfer.md). A JSON backup can preserve more app-specific fields than a generic TSV import. Preview imports and select replacement behavior deliberately.
