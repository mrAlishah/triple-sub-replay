# Changelog (Triple Sub Replay fork)

All notable changes made in this fork. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Upstream releases are tracked in `CHANGELOG.md`; fork entries live only here.

## [Unreleased]

### Added

- **Open in Google Translate from the selection popup.** A button next to Pronounce shares the selected word, phrase or line to the installed Google Translate app (`ACTION_SEND`, `text/plain`, aimed at that app only). It never opens a web page; a toast says when the app is missing or cannot take the text. The app picks its own languages, because sharing text carries none. In Practice, the saved word, example sentence, translations and review meanings can be selected the same way, with Copy, Pronounce and Google Translate. See `docs/specs/2026-10-28-open-in-google-translate.md`.
- **Send to AnkiDroid from Practice.** The saved-word details in Practice (Vocabulary view, and a review after Reveal) have a Send to AnkiDroid button above Back and Delete. It sends the saved word through the same AnkiDroid send as the word card, with every saved meaning, the notes and the online example, so the note has the same nine `TripleSub Replay v2` fields. Meaning, notes or other edits still pending are saved first, never dropped or sent stale. The button shows progress, ignores taps while sending, and ends as "Sent to AnkiDroid" or shows the failed step in red.
- **Desc: your own notes on a saved word.** Vocabulary and Practice (after Reveal) have a multiline `Desc` field for grammar notes, usage and extra examples in any script, with Save notes, an unsaved-changes hint, and auto-save on Back and on a review rating. Notes are stored with the word (older words start empty), kept when the word is saved again or its meanings or review change, searchable, and carried by backups and the Anki TSV export (trailing `desc` column; older files still import and never erase saved notes). Send to Anki copies them into the `Desc` field once; Anki and Practice are not synced afterwards. See `docs/specs/2026-10-26-anki-third-meaning-and-online-example.md`.
- **Tap words on the third line.** With Word learning and Tap to learn on, the third subtitle line works like the others: select a word or phrase, hear it, translate it (into the learning language), and save it as a word of the third language. No Persian dictionary or analyzer is added; part-of-speech colors do not apply to the third line.
- **Triple subtitles.** The Subtitle languages dialog now has three slots, Original, Second and Third, each with a checkbox and a language list; checked slots show on the video and in the panel in that order. The Third slot is off by default and defaults to Persian, which is laid out right-to-left. Its line is translated from the video's own captions and a failure of it never hides the other lines. See `docs/specs/2026-10-25-triple-subtitles.md`.

### Fixed

- **Send to AnkiDroid says which step failed and no longer fakes success.** Sending now checks the `TripleSub Replay` deck, then the `TripleSub Replay v2` note type, then each note. A missing deck or note type is created and listed again to confirm; an existing one is reused; a note type of the same name with other fields stops the send instead of making a duplicate. A word is marked sent only after AnkiDroid returns the new note's id. AnkiDroid ignores the deck for a single insert, so each card is moved into the deck, and one it will not move is reported ("added, but left in another deck"). Each failure has its own message in all 8 languages, naming only the kind of error. Sent words are tracked per note type, so words sent before to the older `DualSub Replay` type can be sent to the new one. See `docs/specs/2026-10-26-anki-third-meaning-and-online-example.md`.
- **Send to Anki from the word card keeps every meaning.** The word card's Send button used to build the note from the tapped word alone, so the third-language meaning, the third sentence translation and the online example were lost. It now sends what the card shows (and waits while a meaning is still loading). Words go to a new `TripleSub Replay v2` note type with the fields `Word`, `Meaning 1` (second language), `Meaning 2` (third language), `Reading`, `Sentence`, `Translation` (the second then the third line's sentence, one per line, no language labels, right-to-left-safe), `Desc`, `Source` and `Online Example` (a link to the saved clip with its start and end, only when the checkbox is on and the clip is valid). The card back hides empty `Meaning 2`, `Desc` and `Online Example`. The older `DualSub Replay` note type, its notes and review history are never changed; AnkiConnect Android, which cannot create note types, keeps filling an existing six-field `DualSub Replay`. The first send creates the new note type in AnkiDroid. See `docs/specs/2026-10-26-anki-third-meaning-and-online-example.md`.

### Changed

- **Word meanings in every subtitle language.** Tapping a word now shows a separately labeled meaning for each subtitle language that is on (for example English and Persian for a German word), each loaded, retried and edited on its own and laid out right-to-left when needed. Saving keeps every meaning under its language code; Vocabulary and Practice show them (Practice after the answer is revealed), search covers them, and the saved-word view edits each one. Backups keep them, the Anki TSV export gets a trailing `meanings` column (older files still import), and the Anki Meaning field lists each extra language as its own labeled block. Clearing a language's text in the word card and saving removes that saved meaning, and a lookup that takes over 20 s counts as failed so Save is never blocked. Existing saved words, their ids and review schedules are unchanged. See `docs/specs/2026-10-25-triple-subtitles.md` (Revision 2).
- **Exports carry the third line.** The Anki note's Translation field (AnkiDroid and AnkiConnect) lists each saved sentence translation after the second line, one right-to-left-safe block each; the note type and its fields are unchanged. The Anki TSV export gets a trailing `sentenceTranslations` column (`fa: text` per line) that import reads by name, so older files still import.
- **Persian words stay whole.** A zero-width non-joiner between two letters no longer splits a word in tap-to-learn (for example "می‌خواهم"). Saved Persian words with Arabic or Persian spellings of yeh and kaf, or with vowel marks, count as the same word.
- **Saved words keep the third line.** Saving a word while the third subtitle is shown also stores that line's real translation of the sentence under its language code (for example Persian). Pending or failed translations and the word's own two languages are never stored. Saving the same word again keeps its review schedule and earlier translations and adds new languages. Practice and the saved-word view show the extra translations after the answer is revealed; backups include them and older backups still import.
- **RTL checkbox per subtitle slot.** Each slot in the Subtitle languages dialog has an RTL checkbox that shows that line right-to-left (flush right). Only the Third slot is on by default, for Persian; unchecked slots keep upstream's automatic direction.
- **Default second language.** The translation language now defaults to English instead of Vietnamese.
- **Debug build identity.** The debug app is called "Triple Sub Replay" and installs as `com.kienhoang.dualsubreplay.triple`, beside the original app, and is never offered upstream updates.
